### Что нового в 1.0.11

- Исправлен `HTTP 400` при передаче результатов параллельных MCP-вызовов из Hermes. Relay сопоставляет вызовы по их ID и отправляет результаты в исходную ветку Напарника.
- Клиенты Anthropic Messages и OpenAI Chat Completions могут продолжать диалог по истории `messages` без дополнительных настроек или плагинов. При обрыве потока Relay сверяет продолжение с историей Напарника перед повторной отправкой.
- Подтверждённые рассуждения передаются в штатном потоке обоих протоколов. Повторённые клиентом блоки рассуждений исключаются при отправке истории в Напарник.
- Исправлены запуск и остановка настольного сервера, сохранение настроек диалога и отображение лимитов. В трассировке улучшены связи между вызовами и результатами инструментов.
- Добавлен API удаления диалога по запросу клиента. Relay удаляет диалог через Напарник и очищает локальные ссылки на него.

Для подключения выберите `naparnik` у провайдера с адресом и ключом из панели Relay. [Инструкции для клиентов](https://github.com/IngvarConsulting/naparnik-relay/blob/v1.0.11/docs/clients.md)

### Установка

| Система | Файл в Assets |
| --- | --- |
| macOS 14+, Apple Silicon | DMG с пометкой macOS-arm64 |
| macOS 14+, Intel | DMG с пометкой macOS-x64 |
| Windows 10/11 x64 | Установщик Windows-x64.exe |
| Linux x86_64 | Linux-x64.AppImage |

На Mac перетащите приложение из образа в «Программы». Сборки для macOS без нотариализации Apple. Если Gatekeeper блокирует запуск, сначала откройте приложение, затем перейдите в «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» для Naparnik Relay.

В Windows запустите установщик. На Linux разрешите выполнение AppImage в свойствах файла. При переходе с браузерной версии сначала остановите её командой `npm stop`.

В меню значка Naparnik Relay в системном трее выберите **Проверить обновления…**. На macOS значок находится в строке меню. Программа проверяет цифровую подпись обновления. Параметры подключения хранятся отдельно от приложения.
