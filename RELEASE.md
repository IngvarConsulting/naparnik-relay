### Что нового в 1.0.8

«Трассировка» открывается отдельным окном. Слева виден обмен с агентом, справа — с Напарником. Стрелки показывают направление передачи данных, включая связь между вызовом клиентского инструмента и запросом, которым агент вернул результат. Можно переходить по номерам пакетов, читать JSON и SSE с подсветкой и прокручивать колонки синхронно.

В «Настройках» можно выбрать языки новых диалогов и управлять серверными инструментами. Изменения сохраняются сразу. По умолчанию разрешены все серверные инструменты, кроме чтения веб-страниц.

Relay сохраняет привязку чата к ветке Напарника и сверяется с историей после обрыва SSE. В поток ZCode и DeepSeek Harness передаётся содержимое подтверждённых сообщений Напарника. Для заголовков DeepSeek Harness используется отдельный метод `/title`. Добавлен маршрут для явной компактизации на стороне 1С.

Инструкция по подключению описывает настройку обоих клиентов и отключение встроенного `web_search` для сессий DeepSeek Harness с Напарником. [Подключение ZCode и DeepSeek Harness](https://github.com/IngvarConsulting/naparnik-relay/blob/v1.0.8/docs/clients.md)

### Установка

| Система | Файл в Assets |
| --- | --- |
| macOS 14+, Apple Silicon | DMG с пометкой macOS-arm64 |
| macOS 14+, Intel | DMG с пометкой macOS-x64 |
| Windows 10/11 x64 | Установщик Windows-x64.exe |
| Linux x86_64 | Linux-x64.AppImage |

На Mac перетащите приложение из образа в «Программы». Первый релиз без нотариализации Apple. Если Gatekeeper блокирует запуск, сначала откройте приложение, затем перейдите в «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» для Naparnik Relay.

В Windows запустите установщик. На Linux разрешите выполнение AppImage в свойствах файла. При переходе с браузерной версии сначала остановите её командой `npm stop`.

В меню значка Naparnik Relay в системном трее выберите **Проверить обновления…**. На macOS значок находится в строке меню. Программа проверяет цифровую подпись обновления. Параметры подключения хранятся отдельно от приложения.
