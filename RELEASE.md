### Что нового в 1.0.14

- Перед вводом или заменой API-ключа Relay показывает памятку об условиях использования 1С:Напарника и передаче данных. Кнопка «Перейти к входу в 1С» открывает форму авторизации. [Пользовательское соглашение 1С](https://code.1c.ai/user_agreement/)

Для подключения выберите `naparnik` у провайдера с адресом и ключом из панели Relay. [Инструкции для клиентов](https://github.com/IngvarConsulting/naparnik-relay/blob/v1.0.14/docs/clients.md)

### Установка

| Система | Файл в Assets |
| --- | --- |
| macOS 14+, Apple Silicon | DMG с пометкой macOS-arm64 |
| macOS 14+, Intel | DMG с пометкой macOS-x64 |
| Windows 10/11 x64 | Установщик Windows-x64.exe |
| Linux x86_64 | Linux-x64.AppImage |

На Mac перетащите приложение из образа в «Программы». Сборки для macOS без нотариализации Apple. Если Gatekeeper блокирует запуск, сначала откройте приложение, затем перейдите в «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» для Naparnik Relay.

В Windows запустите установщик. На Linux разрешите выполнение AppImage в свойствах файла. При переходе с браузерной версии сначала остановите её командой `npm stop`.

В меню значка Naparnik Relay в системном трее выберите **Проверить обновления…**. На macOS значок находится в строке меню. Программа проверяет цифровую подпись обновления. Параметры подключения хранятся отдельно от приложения.
